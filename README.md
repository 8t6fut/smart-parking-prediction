
Smart Parking Availability Prediction Using Machine Learning

1. Project Overview

This project uses Machine Learning to predict parking occupancy and estimate the number of available parking spaces.

The goal is to help drivers understand parking availability and reduce the time spent searching for parking.

2. Problem Statement

Finding available parking spaces can be difficult, especially in busy areas. This project aims to predict how many parking spaces are occupied using historical parking data.

3. Dataset

The project uses the Birmingham Parking Dataset from the UCI Machine Learning Repository.

Dataset link:
https://archive.ics.uci.edu/dataset/482/parking+birmingham

The dataset contains approximately 35,717 records.

4. Machine Learning Method

- Task: Supervised Learning
- Type: Regression
- Algorithm: Linear Regression
- Target: Occupancy
- Features: Parking system, capacity, hour, minute, and day of the week.

5. Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- GitHub

6. Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

7. Project Status

Phase 1: Project proposal, dataset selection, and first Linear Regression experiment.

Future work will focus on improving the model and developing a parking availability demonstration.
